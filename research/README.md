# Research

Literature digests compiled October 2026. Each topic folder follows the same layout:

- a README
- `01`–`06` synthesis documents (state of the field → architectures → theory → applications → evidence and meta-analysis status → open problems)
- an annotated `bibliography.md` with citation IDs
- a `papers/` folder of open-access PDFs
